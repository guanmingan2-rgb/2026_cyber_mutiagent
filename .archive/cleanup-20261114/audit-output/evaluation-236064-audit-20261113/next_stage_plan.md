# 后续评测计划

**正式 12 题及扩大样本均为 NO-GO。** 现有证据支持将 236064 作为单题官方动态评分基线。精确镜像身份、独立可信签名、正式隔离覆盖和跨任务运行能力仍待核验。附件预算为建议值，未提供正式执行和费用授权。

下一步可用无害 fixture 验证并发、取消、恢复、路径隔离和落盘。评分侧可完善离线签名关联和指标归集，再以运行前的元数据审查任务池。把基线所用的 5 小时 Slurm 上限和 4 小时 Agent 预算与建议的 45 分钟区分开，正式研究中把时间预算变化记录为单独条件。

后续若具备合规评测数据，先对同一冻结任务集报告单 Agent 基线，再开展 Manager、Critic、Verifier 的静态代码审查对照。统一模型标识、任务、预算和判定口径，逐项变更，保留按题配对的完成率、审查质量、成本和失败原因。
