# 失败分类与当前瓶颈

先导未执行，以下是分类口径，无先导失败计数。

- Agent 决策失败、无进展或最终选择无效，使用会话终止原因和选择状态。
- 环境构建或依赖失败，使用准备阶段、构建日志和资源门禁状态。
- 评分提交、执行或验证失败，使用评分状态、候选身份核验和两侧结果。
- 崩溃类型或位置不匹配，使用独立签名结果。Fixed 未通过单列。
- Slurm/HPC、API、超时和预算耗尽，按最先有证据支持的根因分类，保留其余状态作诊断。
- 无法归因的结果记录为其他或未知。基础设施重试应保留原 attempt，不能覆盖结果。

236064 的主要可量化等待是 Slurm 排队 49 分 36 秒。一次成功无法衡量 Agent 在不同任务上的能力。现有工程风险主要在同节点并发、超时恢复、镜像身份绑定和独立签名证据。费用上限需要可信的执行前预算控制，历史账本支持事后估计。
